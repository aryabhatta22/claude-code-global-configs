# "What's next" logic (generic)

Use when starting a session and unsure what to pick up, or when asked
"what's next" / "where did we leave off".

## Steps

1. Read the project's tracker (whatever file/tool it actually uses —
   check `TRACKER-CONVENTION.md` habits first).
2. List tickets/tasks not marked done.
3. Drop any that are blocked — waiting on another ticket, waiting on an
   open question, or waiting on someone else's input.
4. Of what's left, prefer (in order):
   - anything already marked "in progress" / "code-complete but not
     verified" — finish it before starting something new,
   - anything blocking other open tickets,
   - the next ticket in the tracker's stated order.
5. Report: the one ticket to pick up next, one line on why it's next,
   and — if relevant — one line naming what's blocked and on what.

Don't just report the full open list — give one clear pick, with the
reasoning, so the session can start working immediately.
